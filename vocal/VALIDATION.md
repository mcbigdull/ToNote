# 验证记录

日期：2026-09-22。Windows，项目内 Python 3.11.16，PyTorch 2.5.1+cpu，FFmpeg 7.1（imageio-ffmpeg 提供）。

- 16 项单元测试通过：颤音和 20ms 八度异常、稳定滑音目标、半音变化、呼吸间隔、低置信度过滤、变速节拍映射、MIDI 秒级起止和音色、网格冲突、MusicXML 休止与跨小节连音、非法配置、FFmpeg 缺失、CPU 回退、模型下载失败、无节拍、CREPE 音域限制、失败记录及不覆盖历史结果。
- 合成旋律：22050 Hz 双声道，四个已知音符 C4/E4/G4/A4，带颤音和静音。实际经过 FFmpeg、重采样，分别使用 pYIN 和 CREPE full CPU 后端，均识别四音正确；生成的 MIDI 与 MusicXML 可以重新解析；中文及空格路径通过。重复运行创建独立目录，关闭中间文件保留后 WAV 移除而 CSV 保留。空白 WAV 明确失败且不生成空 MIDI。
- 实际歌曲：`莫非定律乐团 - Lidocaine.mp3` 的第 45–65 秒。真实下载 htdemucs 权重、在 CPU 分离，再由 pYIN 提取 F0，从原始片段自动分析节拍。结果：37 个音符，117.1875 BPM，估计 C major；MIDI、MusicXML、CSV、PNG 均成功生成。
- 真实歌曲结果位于 `../output/validation/results/莫非定律乐团 - Lidocaine 验证片段_wibcw0af/`。调试图由实际输出生成；当前工具环境无法直接打开该目录下的图片做目视检查。
- 本次没有运行整首歌曲，没有实际 CUDA 硬件验证，也没有做人工旋律标注或逐音准确率测量。调号和节拍是算法估计，需人工复核。
