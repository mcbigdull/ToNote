# 《天鹅》参考谱

来源：用户于 2026-10-16 在对话中提供的单页小提琴谱图片，标题为 *The Swan (Le Cygne), from Carnival of the Animals*，署名 Camille Saint-Saëns。

图片可见内容：高音谱号、一个升号、6/4、Adagio。未见数字 BPM；上方 1/2/3/4 为指法，弧线包括连弓与延音。本图小提琴声部未见明显竖直叠置的双音或和弦，但这不能单独证明音频完全按图演奏、没有双音或伴奏残留。

放大后按真正小节线核对，共28小节；七行分别为3、4、4、4、4、4、5小节。首尾有整小节休止。第2小节的E5等向下符干不是小节线；高音区附点全音符也不能误读为休止。

`the_swan_opening_manual.csv` 只人工转写了开头整小节休止之后的六个音。它没有演奏秒级时间，没有完成全曲转写，不能直接当作完整评测真值。

后续新增 `the_swan_score.json`，已人工录入全谱28小节的音高、时值、休止和同音延音。它是可复核的人工初稿，不能视为专业校订后的真值。第15小节的F♯5到E5为下行连弓，不是同音延音。按音频估计时间的热图及逐音CSV见 `../output/reference_comparison/`；估计的秒位置不用于起止准确率评测。
